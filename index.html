AI Playlist Creator · desktop app
Desktop app

AI Spotify Playlist Maker

Describe a mood, something like "rainy afternoon lo-fi with a bit of jazz", and a real playlist shows up in your Spotify account. Gemini turns the description into artist and genre queries, Spotipy builds the playlist, and the Tkinter window stays responsive because the API calls run on a background thread.

  • Python
  • Gemini API
  • Spotify Web API
  • Tkinter

Discord bot

Shrimpy, a Discord music bot

Plays YouTube audio in voice channels through slash commands. /play takes a search, a link or a whole playlist, and each server gets its own queue with shuffle, loop modes and volume. Audio runs on a separate Lavalink node, and the bot reconnects on its own if that node drops.

  • Python
  • Discord API
  • Lavalink v4
